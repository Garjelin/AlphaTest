# Bin Lookup App

## Описание

Bin Lookup App — это Android-приложение для получения информации о банковских картах по их BIN (Bank Identification Number). Приложение позволяет пользователю:
- Вводить BIN (6–8 цифр) и получать данные о карте (страна, координаты, тип карты, банк) с использованием API https://binlist.net/.
- Переходить по URL банка, номеру телефона или координатам в соответствующие приложения (браузер, звонилка, карты).
- Просматривать историю предыдущих запросов, которая сохраняется локально и доступна после перезапуска приложения.

Приложение разработано в соответствии с принципами Clean Architecture, использует современный стек технологий и минималистичный интерфейс.

## Функциональность

1. **Главный экран**:
   - Ввод BIN и отображение информации о карте (страна, координаты, тип карты, банк).
   - Поддержка перехода по URL, телефону и координатам.
   - Кнопка для перехода к истории запросов.
   - Отображение ошибок (например, неверный BIN или проблемы с сетью).
   - Индикатор загрузки.

2. **Экран истории**:
   - Список всех предыдущих запросов с информацией о карте.
   - Данные сохраняются локально с использованием Room и отображаются в порядке от новых к старым.
   - Поддержка перехода по URL, телефону и координатам из истории.

## Используемые технологии

- **Язык программирования**: Kotlin
- **Архитектура**: Clean Architecture (data, domain, presentation)
- **UI**: Jetpack Compose
- **Паттерн**: MVVM
- **Асинхронность**: Kotlin Coroutines
- **DI**: Koin
- **База данных**: Room
- **Сеть**: Retrofit
- **Логирование**: Timber
- **Навигация**: Jetpack Navigation Compose
- **API**: https://binlist.net/

## Требования

- Android SDK 26+ 
- Устройство или эмулятор с доступом в интернет

## Установка

1. Склонируйте репозиторий:
```bash
git clone https://github.com/Garjelin/AlphaTest.git
```
2. Откройте проект в Android Studio.
3. Убедитесь, что у вас настроен Gradle и установлены необходимые зависимости.
4. Соберите и запустите приложение на устройстве или эмуляторе:
```bash
./gradlew build
```

## Использование

1. На главном экране введите BIN (6–8 цифр) и нажмите "Search".
2. Просмотрите информацию о карте. Нажмите на координаты, URL или телефон, чтобы открыть соответствующее приложение.
3. Перейдите на экран истории через кнопку "View History", чтобы увидеть список предыдущих запросов.
